# Производители и поставщики — единый согласованный перечень

Все перечисленные сайты допущены для поставки в Москву/МО по решению заказчика. Это не подтверждение наличия, самовывоза, НДС или реквизитов продавца конкретной карточки. Пустые ИНН/КПП означают, что реквизиты не установлены. Исторический резервный файл больше не используется.


## Выбранный способ получения данных

Настройка заполнена 13.11.2026: для каждого сайта выбран ровно один способ — `browser` (браузер) или `http` (HTTP-загрузка HTML). Это выбор для будущего использования, а не свежая проверка всех сайтов. Автоматическое переключение способов этим справочником не задаётся: если выбранный способ не работает, его меняют отдельно после проверки.

Установленная версия 214 читает первые четыре колонки; добавленные поля пока не управляют её маршрутами. Код движка и сервер в этой задаче не изменены. Дата свидетельства — дата наблюдения, а не дата заполнения. Историческая проверка цены одной карточки не подтверждает весь сайт, авторизацию, наличие, продавца или финансовую пригодность предложения. Требование входа для всех строк остаётся неустановленным.

Основания: `docs/SUPPLIER_AUDIT.md`, `engine/audit_suppliers.py` (открытие через browser.page), установленный `engine/browser.py` и `engine/search/whitelist.py`; TASK0464 lead-0464-current-chrome-ssc240-observed-20261113 содержит текущее ручное наблюдение Chrome для ChipDip. HTTP-колонка исторического аудита обозначает ответ при навигации браузера, а не самостоятельную HTTP-проверку. Для Электромеханики исходный код отдельно подтверждает HTTP-загрузку с последующим set_content. Отсутствие подтверждения в рассмотренных материалах не означает, что сайт нигде ранее не проверялся.
