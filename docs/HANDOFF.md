## LLM = DeepSeek (с июня 2026)
- Закончились кредиты Anthropic → переключились на **DeepSeek** (`LLM_PROVIDER=deepseek` в `.env`,
  модель `deepseek-chat`). Вызов через OpenAI-совместимый endpoint в `engine/llm.py` (httpx, JSON-режим).
  Текст/поиск/матчинг/реквизиты работают на DeepSeek (проверено живыми запросами).
- Назад на Claude — сменить `LLM_PROVIDER=anthropic` (ключ Anthropic и модели на месте).
- ⚠ **У DeepSeek нет vision.** Сканы спецификаций распознаёт **локальный OCR** (см. ниже), а не модель.

## Что РАБОТАЕТ вживую (проверено)
- **Распознавание спецификации** (`POST /parse`): принимает **PDF, DOCX, XLSX/XLS** (диспетчер по
  расширению в `spec_pdf.parse_spec`; DOCX — python-docx, XLSX — openpyxl). Текстовые PDF напрямую;
  **сканы → локальный OCR** (`_ocr_backend()`): macOS — Apple Vision (`ocrmac`, без Homebrew),
  Linux/VPS — Tesseract. OCR-текст → DeepSeek. Claude vision — фолбэк только при `LLM_PROVIDER=anthropic`.
- **База-кэш позиций** (`engine/search/base_db.py`): результаты поиска (цены/скриншоты/реквизиты)
  кэшируются в `engine/data/base/index.json` и переиспользуются. Поиск **cache-first**: сперва
  `base.lookup` (без браузера), вживую — только промахи (и они пополняют базу). Матчинг позиции:
  точный нормализованный ключ (имя|марка|дисциплина) → LLM-фолбэк (DeepSeek). Дата в документах
  всегда текущая. Управление: `/base`, `/base/refresh` (фоновая джоба), `/base/add`, `DELETE /base/{key}`;
  в UI карточка «База цен». Обновлять раз в месяц кнопкой (cron — после VPS).
- **Поиск цен** (`POST /search_position`): выдача через **SERP-API XMLRiver** (без капчи, ключи в
  `.env`), браузер только для скриншотов карточек (headless, `BROWSER_HEADED=false`). Сначала ищет
  по **доверенным поставщикам** (`Поставщики.md`, `site:`-выдача), затем при числе офферов
  <`MIN_SOURCES` — по отдельному резерву Москвы/МО (`Поставщики_резерв_Москва.md`). Произвольная
  интернет-выдача в доборе не используется. Извлечение цены/региона/ИНН — DeepSeek. Капча-страницы магазинов отсекаются
  (`_looks_like_bot_check`), ИНН проверяется по контрольным цифрам (`valid_inn`). `MIN_SOURCES=5`,
  `TOP_PRICES=3`. API и UI передают единицу измерения позиции; цены упаковок пересчитываются в
  цену за эту единицу. Диагностика `[поиск]`/`[реквизиты]` в окно движка.
  XMLRiver ограничен четырьмя одновременными запросами, использует 30-секундный таймаут и один
  повтор при медленном/временном ответе. Браузер ждёт первый ответ до 10 секунд, повторяет
  навигацию один раз и при двух таймаутах пробует исходный HTML обычным HTTP-запросом.
  Оборудование «Графтио» из спецификации (позиции 1–8, 13–14) не ищется у
  интернет-поставщиков. Парсер помечает его уникальным даже при типичных ошибках
  OCR в имени производителя; эти позиции остаются в документе для внутренней цены.
  Для работы из-за рубежа браузер можно направить через локальный mixed-proxy:
  `BROWSER_PROXY_SERVER=http://127.0.0.1:2080`. `BROWSER_CHANNEL=chrome` использует установленный
  Google Chrome с нативным User-Agent; `BROWSER_HEADED=true` требуется сайтам, которые блокируют
  headless-браузеры. Внутренний аудит 28 сентября после повторной проверки показывает 30/34
  извлечённых цен, но включает агрегатор `poisk.im` и корпоративный `russvet.ru` в общем числе:
  среди 32 прямых поставщиков цена подтверждена на 29. `artem-tools.ru` работает через локальный
  постоянный профиль Chrome после ручной проверки KillBot; `vseinstrumenti.ru` по-прежнему
  возвращает автоматическому браузеру 403. Обычный Chrome открывает карточку с ценой,
  но Playwright и прямой HTTP-запрос через тот же прокси получают 403: надёжный скрапинг
  в текущей конфигурации не работает. Нужен согласованный B2B-прайс/API либо ручное
  подтверждение цены. Эти цифры не означают готовность всех поставщиков.
  Сквозной поиск по лотку DKC 3526210 нашёл 5/5 предложений, но вскрыл старую неполную запись
  базы: сборка ошибочно брала из неё одну цену. Теперь неполная база запускает живой поиск.
  Карточка `rs24.ru/product/162367` показывает 3 151,26 ₽ за штуку длиной 3 м и кратность
  заказа 8 штук; прежнее извлечение дважды дало неверную цену за метр. Добавлено чтение выбранной
  единицы продажи и длины из DOM; прежние записи базы помечены как требующие обновления, так как
  могли содержать неверную единицу или модификацию товара. После изменения разметки `rs24.ru`
  селектор единицы продажи обновлён: живая проверка 28 сентября подтвердила 1 050,42 ₽/м.
  Сквозной расчёт позиции 23 нашёл 5/5 предложений и создал КАЦ/ТКП; готовность всей
  спецификации и всех поставщиков этим не подтверждается.
- **Аудит поставщиков:** `python -m engine.audit_suppliers` проверяет каждый основной и резервный
  домен на реальной карточке через XMLRiver → браузер → LLM-извлечение цены. Для повторной

- **Реквизиты продавца**: для доверенных поставщиков берутся из `Поставщики.md`; иначе добираются
  с сайта магазина (`engine/requisites/supplier.py`). В Том ТКП пишутся **текстом** (Наименование/
  ИНН/КПП) — скриншот реквизитов не снимается.
- **Сборка** КАЦ/ТКП/ТСН и фильтр «ТСН>КАЦ → исключить» — готовы и протестированы
  (`engine/builders/*`; тесты `engine/test_build_manual.py`, `engine/test_endpoints.py`, `demo_run.py`).
- **UI** (`web/index.html`, `web/app.js`): 3 шага (параметры+файлы → таблица позиций/цен → сборка)
  + карточка «База цен». Миниатюры скриншотов с зумом, «найти цены» по одной и «по всем», индикатор

## Важные gotchas (не наступать повторно)
- **UI открывать с движка** (`http://127.0.0.1:8765/`), не с https-Pages — иначе Safari блокирует
  обращения к http-localhost (mixed content).
- **`/parse` блокирует event loop** (async-эндпоинт зовёт синхронный `parse_spec`) — во время разбора
  движок не отвечает (в т.ч. `/health`). Кандидат на улучшение: вынести в threadpool.
- **Выдача — через XMLRiver** (SERP-API, ключи в `.env`), капчи нет. Официальный Yandex Search API
  новым аккаунтам недоступен; браузерный поиск выдачи остался лишь крайним фолбэком. Браузер нужен
  только для скриншотов карточек (headless ок; магазины капчу обычно не показывают — кто показывает,
  отсекается). Старый `cookies.json` от ручной капчи больше не критичен.
- **После правок `.env` или кода — перезапуск движка** (`start.command`), статичный JS — Cmd+Shift+R.
- Конфиденциальные данные обезличены; «уникальные» производители задаются через `CUSTOM_MAKERS` в `.env`.

## ТСН-2001 — решено (локальный справочник)
Логика: `ТСН_тек = база × коэффициент`; если `ТСН_тек > макс. цена КАЦ` → позиция исключается из КАЦ
и помечается в файле ТСН. Реализовано через **локальные справочники** в корне репо
(`engine/tsn/local_db.py`): базовая расценка из `ТСН-2001_электро_автоматика.md` (LLM-матчинг),
коэффициент из `индексы.md`. Пути — в `config.py` (`TSN_REFERENCE_FILE`, `TSN_INDICES_FILE`).
`mos.ru` (`engine/tsn/mos_ru.py`) больше не используется (недоступен под VPN). Индексы по видам
работ заполняются в `индексы.md` вручную раз в квартал (незаполненные фолбэчат на «оборудование»).
