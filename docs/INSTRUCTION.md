# Инструкция сметчику

> Текущий поток и правила — 15.10.2026. Два приложения на одном движке: **Сметчик** (`/`) и
> **База-менеджер** (`/base.html`). Здесь — про Сметчик. Технические детали — в
> [`HANDOFF.md`](HANDOFF.md) и [`DEVELOPER_ONBOARDING.md`](DEVELOPER_ONBOARDING.md).

## Что делает приложение

По спецификации оборудования (проектная документация, в т.ч. сканы) и письмам с ценами на
уникальное оборудование формирует документы:

1. **Том ТКП** (PDF) — скриншоты карточек товара с сайтов + панели реквизитов продавцов (текстом).
2. **КАЦ** (Excel) — три наибольшие допустимые цены независимых продавцов на обычную позицию,
   цена без НДС, реквизиты, ссылки, № страницы в Томе ТКП.
3. **Файл ТСН-2001** (Excel) — сравнение с расценками ТСН-2001. Если расценка ТСН-2001 в текущих
   ценах выше цены КАЦ — позиция исключается из КАЦ. *(Сейчас ТСН скрыт из интерфейса, вернётся
   позже; файл собирается только при ручном вводе расценок.)*

## Один раз: настройка движка на вашем компьютере

1. Установите Python 3.11+ (для Windows — разрешите запуск скриптов).
2. Первичная установка окружения:
   - Windows: двойной клик по `engine/run.cmd`
   - macOS/Linux: `./engine/run.sh`
   (создаёт виртуальное окружение, ставит зависимости и браузер, создаёт `engine/.env`)
3. Откройте `engine/.env` и впишите ключи, которые вам передали:
   - `LLM_PROVIDER` и ключ выбранного провайдера — разбор неподдерживаемого текста, сканов и писем;
     поддерживаются Anthropic, DeepSeek и Cloud.ru, активная настройка зависит от окружения
   - `DADATA_TOKEN` — реквизиты организаций по ИНН
   - `XMLRIVER_KEY` (+ `XMLRIVER_USER`) — поиск цен без капчи
4. **Дальнейший запуск — двойной клик по `start.command`** в корне (не `run.sh` — он подвисает на
   переустановке). В окне появится `Движок запускается на http://127.0.0.1:8765/`, браузер
   откроется сам.

> Браузер и HTTP-запросы к поставщикам используют настроенный маршрут. Его доступность и
> география не гарантируются самим запуском приложения. Ошибки и отложенные источники
> сохраняются как незавершённые результаты, а не как отсутствие товара.

## Каждый раз: формирование документов (страница «Сметчик»)

1. Откройте **`http://127.0.0.1:8765/`** (не адрес GitHub Pages — с него запросы к движку
   блокируются браузером).
2. Убедитесь, что вверху написано «движок на связи».
3. Заполните: наименование объекта, дисциплину (ЭМ/АК), дату фиксации.
4. В поле «Уникальное оборудование» перечислите через «;» подстроки наименований, цены на которые
   берутся из писем (например: `щит спецзаказа; уникальный модуль`). Такие позиции не ищутся и в
   Том ТКП не попадают.
5. Загрузите спецификации (**PDF / DOCX / XLSX**) и письма/счета (PDF).
6. Нажмите «Распознать и найти цены». Для поддерживаемых текстовых PDF используются исходные
   таблицы; иначе текст разбирает настроенный провайдер. Сканы зависят от настроенного
   распознавания и могут требовать сверки. Устанавливать локальный OCR для этого потока не нужно.
   Поиск запускается автоматически; проверяйте поля и причины недобора по мере поступления результатов.
7. Проверьте и поправьте таблицу позиций (цены, поставщики, город склада, скриншоты).
8. Сохраните черновик или скачайте сводку поиска с доступными приложениями даже при недоборе.
   После завершения обработки исходников и выполнения условий допустимости нажмите
   «Сформировать документы», следите за прогрессом, скачайте Том ТКП и КАЦ.

## Важные правила (заложены в логику)

- План поиска использует только единый согласованный `Поставщики.md` (36 сайтов без резервной фазы). Москва/МО допускается по перечню сайтов, а не по наличию склада/самовывоза карточки. Наличие, НДС и продавец не выводятся из допуска. Неактивный исторический `Поставщики_резерв_Москва.md` не читается.
  Начальные групповые запросы охватывают весь перечень. Последующие проверки назначаются
  по результатам источников; произвольные сайты из интернета не добавляются. План охвата
  не гарантирует успешного доступа к каждому поставщику: отказы и незавершённые проверки видны отдельно.
- Для итоговых документов нужны три независимых допустимых продавца на обычную позицию;
  выбираются три наибольшие сопоставимые цены. Число найденных кандидатов не равно числу
  допустимых продавцов. Поиск не заканчивается на первых трёх: сохраняется полнота назначенных источников.
- Уникальная цена из письма и собственное оборудование Графтио — отдельные случаи.
  При отсутствии цены Графтио это указано явно; полная стоимость не определяется.
- Снимок карточки — вспомогательное приложение с источником и датой. После одной ограниченной
  попытки неудача съёмки показывается предупреждением и сама по себе не отменяет допустимую цену.
  Автоматическая проверка содержимого снимка не требуется; правила товара, цены, единицы и продавца сохраняются.
- Неизвестный регион поставки — предупреждение, а не самостоятельная причина исключения цены.
  Москва не предполагается без данных; явно несовместимые условия поставки блокируют итоговую сборку.
- Графа «без НДС» рассчитывается из принятой цены делением на `1 + VAT_RATE / 100`;
  значение настройки по умолчанию — 22% (делитель 1.22). Это правило выходного шаблона,
  а не подтверждение налоговых условий каждого продавца: неизвестный НДС в исходнике
  не становится подтверждённым из-за этого расчёта. Сохраняйте исходные коммерческие условия.
- Цены из писем идут в КАЦ одной строкой и НЕ попадают в Том ТКП.
- Расценки ТСН-2001 берутся из локального справочника (`ТСН-2001_электро_автоматика.md`),
  коэффициент пересчёта — из `индексы.md` (обновляется раз в квартал). Если ТСН-2001 > КАЦ —
  позиция исключается из КАЦ.

## Наполнение базы цен (страница «База-менеджер»)

- **Импорт из Excel:** загрузите список позиций (столбцы «Наименование» обязательно, плюс
  «Тип/марка», «Ед.», «Дисциплина») — движок найдёт цены по каждой и сохранит блоки в базу.
- **Вручную:** введите наименование → «Найти и добавить в базу», либо найдите цены по всем
  позициям сразу, поправьте офферы и «Сохранить всё в базу».
- **Чтение каталога:** повторная загрузка спецификации для известного товара и заполнение
  из каталога используют сохранённые наблюдения и сами по себе не обновляют цены и даты.
- **Обновление цен:** отдельный запуск `engine/run_catalogue_refresh.py` повторно проверяет
  записанные карточки без нового поиска поставщиков. Ежедневное расписание, если оно нужно,
  настраивается отдельно; наличие команды не означает, что такое расписание уже работает.
- **Прежняя база:** кнопка «Обновить базу (переискать всё)» в База-менеджере вызывает повторный
  поиск по всей прежней базе. Это отдельная сетевая операция, а не чтение каталога или
  обновление только записанных карточек; она не является обязательным ежемесячным действием.

## Если что-то не нашлось

Если по позиции мало источников или не определился регион/реквизиты — она помечается в логе и в
таблице. Поправьте вручную: кнопка «📷» снимает скриншот и добирает реквизиты по указанному URL,
поля цены/поставщика/ИНН редактируются прямо в строке.
