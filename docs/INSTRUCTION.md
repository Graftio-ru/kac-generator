# Инструкция сметчику

> Актуально на июнь 2026. Архитектура — два приложения на одном движке: **Сметчик** (`/`) и
> **База-менеджер** (`/base.html`). Здесь — про Сметчик. Технические детали — в
> [`HANDOFF.md`](HANDOFF.md) и [`DEVELOPER_ONBOARDING.md`](DEVELOPER_ONBOARDING.md).

## Что делает приложение

По спецификации оборудования (проектная документация, в т.ч. сканы) и письмам с ценами на
уникальное оборудование формирует документы:

1. **Том ТКП** (PDF) — скриншоты карточек товара с сайтов + панели реквизитов продавцов (текстом).
2. **КАЦ** (Excel) — конъюнктурный анализ: до 3 максимальных цен на позицию (самовывоз Москва/МО),
   цена без НДС, реквизиты, ссылки, № страницы в Томе ТКП.
3. **Файл ТСН-2001** (Excel) — сравнение с расценками ТСН-2001. Если расценка ТСН-2001 в текущих
   ценах выше цены КАЦ — позиция исключается из КАЦ. *(Сейчас ТСН скрыт из интерфейса, вернётся
   позже; файл собирается только при ручном вводе расценок.)*

## Один раз: настройка движка на вашем компьютере

1. Установите Python 3.11+ (для Windows — разрешите запуск скриптов).
2. Первичная установка окружения:
   - Windows: двойной клик по `engine/run.cmd`
   - macOS/Linux: `./engine/run.sh`
   (создаёт виртуальное окружение, ставит зависимости и браузер, создаёт `engine/.env`)
3. Откройте `engine/.env` и впишите ключи, которые вам передали:
   - `DEEPSEEK_API_KEY` — распознавание и извлечение данных (основной)
   - `DADATA_TOKEN` — реквизиты организаций по ИНН
   - `XMLRIVER_KEY` (+ `XMLRIVER_USER`) — поиск цен без капчи
4. **Дальнейший запуск — двойной клик по `start.command`** в корне (не `run.sh` — он подвисает на
   переустановке). В окне появится `Движок запускается на http://127.0.0.1:8765/`, браузер
   откроется сам.

> Движок открывает браузер на вашем компьютере (российский IP) — так магазины не блокируют
> автопоиск. Окно во время работы можно не трогать (оно скрыто, если не просит капчу).

## Каждый раз: формирование документов (страница «Сметчик»)

1. Откройте **`http://127.0.0.1:8765/`** (не адрес GitHub Pages — с него запросы к движку
   блокируются браузером).
2. Убедитесь, что вверху написано «движок на связи».
3. Заполните: наименование объекта, дисциплину (ЭМ/АК), дату фиксации.
4. В поле «Уникальное оборудование» перечислите через «;» подстроки наименований, цены на которые
   берутся из писем (например: `щит спецзаказа; уникальный модуль`). Такие позиции не ищутся и в
   Том ТКП не попадают.
5. Загрузите спецификации (**PDF / DOCX / XLSX**) и письма/счета (PDF).
6. Нажмите «Распознать и взять из базы» — позиции подтянутся из накопленной базы цен.
   Помеченные красным «нет в базе» — добавьте через **База-менеджер** или заполните вручную здесь.
7. Проверьте и поправьте таблицу позиций (цены, поставщики, город склада, скриншоты).
8. Нажмите «Сформировать документы», следите за прогрессом, скачайте Том ТКП и КАЦ.

## Важные правила (заложены в логику)

- Цены — максимально высокие: по каждой позиции берутся 3 наибольшие из найденных (цель — не
  меньше 5 источников; фактическое число — в индикаторе «найдено N из M»).
- Подходят предложения с самовывозом из Москвы/МО (склад может быть в любом регионе — не-московские
  подсвечиваются, поправьте вручную).
- НДС = 22% (графа «без НДС» = цена / 1.22).
- Цены из писем идут в КАЦ одной строкой и НЕ попадают в Том ТКП.
- Расценки ТСН-2001 берутся из локального справочника (`ТСН-2001_электро_автоматика.md`),
  коэффициент пересчёта — из `индексы.md` (обновляется раз в квартал). Если ТСН-2001 > КАЦ —
  позиция исключается из КАЦ.

## Наполнение базы цен (страница «База-менеджер»)

- **Импорт из Excel:** загрузите список позиций (столбцы «Наименование» обязательно, плюс
  «Тип/марка», «Ед.», «Дисциплина») — движок найдёт цены по каждой и сохранит блоки в базу.
- **Вручную:** введите наименование → «Найти и добавить в базу», либо найдите цены по всем
  позициям сразу, поправьте офферы и «Сохранить всё в базу».
- **Поддержание:** раз в месяц — «Обновить базу (переискать всё)».

## Если что-то не нашлось

Если по позиции мало источников или не определился регион/реквизиты — она помечается в логе и в
таблице. Поправьте вручную: кнопка «📷» снимает скриншот и добирает реквизиты по указанному URL,
поля цены/поставщика/ИНН редактируются прямо в строке.
